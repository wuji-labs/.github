# Security Policy

## Reporting a vulnerability

These are documentation / prompt skills rather than running services, so the
attack surface is small. Still, if you find:

- a prompt-injection pattern that makes a skill behave unsafely,
- a benchmark or helper script with an unsafe file/network operation, or
- leaked credentials or private data in any file,

please report it privately to **okeah631@gmail.com** rather than opening a public
issue. We aim to acknowledge reports within 7 days.

Please do not include real personal, medical, or financial data in reproduction
steps.
