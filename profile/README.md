## 华夏十大 · HuaXia Skills

Ten open-source AI skills, each distilling one classical Chinese source into a
capability AI can actually use. Install the whole family with one command:

```
/plugin marketplace add wuji-labs/huaxia-skills
```

| Skill | Gives AI… | Source |
|------|-----------|--------|
| [nopua](https://github.com/wuji-labs/nopua) | courage & character — drive by trust, not fear | 道德经 Dao De Jing |
| [tiangong](https://github.com/wuji-labs/tiangong) | aesthetics & craft | 考工记 · 天工开物 · 园冶 |
| [bibuzaohua](https://github.com/wuji-labs/bibuzaohua) | literary soul | 诗经 · 楚辞 |
